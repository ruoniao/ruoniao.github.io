# 个人网站维护

网站继续使用 Jekyll，可由 GitHub Pages 构建，无需服务器或 AI 接口。Three.js 0.170.0 和控制器随仓库提供，访问知识页面时不依赖第三方 CDN。

## 常见更新

| 内容 | 文件 |
|---|---|
| 姓名、介绍、经历、项目、公开联系资料 | `_data/profile.json` |
| 知识点、层级、关联、掌握程度、文章链接 | `assets/data/knowledge.json` |
| 山峰位置、镜头和可选节点坐标 | `assets/data/knowledge-layout.json` |
| 文章 | `_posts/` |

Home 和 About 共用个人资料。`experience` 当前为空，未编造工作或教育经历。首页介绍是根据已有公开文章起草的初稿，可直接修改。

`resume_url` 当前为 null，下载按钮明确显示待补充。将真实简历放到 `assets/resume.pdf`，再将该字段改为 `/assets/resume.pdf`，下载按钮自动启用。另有“打印 / 保存此页为 PDF”使用浏览器打印功能，不等同于已经准备好的正式简历。

项目 `url` 和可选 `article` 可填站内地址或 HTTPS 地址。不要把私人地址、证件号或不希望公开的资料放进这些数据文件。

## Blog

Front Matter 的 `section` 取 `tech`（技术）或 `notes`（杂记）。原 `categories` 继续保留细分主题。文章按原 `date` 倒序展示，`published: false` 继续不公开。可选 `description` 用于手写摘要，否则提取正文开头。

旧文章 permalink 不变；`/articles`、`/articles-zh`、`/categories` 保留转到 Blog 的入口。

## 知识数据

```json
{
  "id": "kv-cache",
  "title": "KV cache",
  "parent": "inference",
  "domain": "models",
  "description": "缓存容量、上下文长度和并发预算。",
  "stage": null,
  "evidence": [
    {"title": "模型的几个估算问题", "url": "/blog/模型的几个估算问题/"}
  ]
}
```

`id` 稳定且唯一。`parent` 为所属层级的父节点，根节点为 null；`domain` 必须存在于 `domains`。额外跨领域关联放在 `relations`，不会改变父子层级。文章链接只代表记录，不自动改变能力评级。

`stage`：null=待评估，0=未开始，1=已接触，2=辅助应用，3=独立应用，4=总结指导。初始 28 个知识点均未评级。由本人确认后更新颜色；不根据文章数量推断熟练程度。

新增知识点只需编辑 JSON。新增一个领域时，另在 `knowledge-layout.json` 的 `domains` 中提供其山峰的 x、z、radius、height。节点默认按稳定 ID 和层级定位，也可增加 `nodes: {"kv-cache": {"x": 20, "z": 10}}` 固定位置。增加同级节点不会导致其他同级节点重新排列。

数据不包含实际掌握比例。远景山峰是未知空间的视觉隐喻，不伪装成具体技能。

## 运行与验证

```sh
bundle install
bundle exec jekyll build --destination ../site-preview
python scripts/validate_site.py ../site-preview
python -m http.server 4173 --bind 127.0.0.1 --directory ../site-preview
```

访问本地 4173 端口。地图支持拖动旋转、右键平移、滚轮缩放；触屏支持单指旋转和双指操作。键盘聚焦地图后方向键平移、+/- 缩放、Home 回全景、Esc 退出登山或关闭面板。知识目录提供不依赖三维精细点击的等价内容访问。WebGL 不可用时自动显示目录。

发布前检查：首页和 About 的本人资料、简历文件、知识评级、Blog 分类、旧文章链接、移动布局。合并到 main 将触发当前仓库的 GitHub Pages 发布。

## 渲染实现

山体是带高度场的真实三角网格，叠加线框、等高采样点和知识路径；镜头变化会产生透视与遮挡。它不是图片背景。地形是程序生成的全息表达，不是照片级山脉扫描。地形数据与知识内容独立；浏览器仅渲染，不请求模型服务。

首页不加载 Three.js；仅知识页加载三维库。低宽度设备降低地形分段数，限制像素比，隐藏页面停止渲染；标签按距离、重叠和山体遮挡裁剪。正式上线后仍应在真实低端手机上补充性能测试。
